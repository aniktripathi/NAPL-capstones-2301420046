# NAPL-capstones-2301420046
Project Title: Smart Personal Finance and Expense Tracker Using Go
Description: A web-based application developed using Go GolangGolang that helps users manage their income, track daily expenses, set monthly budgets, and monitor savings. It provides interactive dashboards, category-wise expense charts, and financial reports. Advanced features can include budget alerts and machine learning-based expense prediction. The system uses a MySQL/PostgreSQL database to store financial records securely.
Tech Stack: Go, Gin, PostgreSQL/MySQL, HTML/CSS/JavaScript or React, REST APIs, and optional Python for machine learning.
